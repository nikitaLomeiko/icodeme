Задача: Разработать максимально подробный, глубокий и структурированный план обучения языку программирования JavaScript.

На входе дана строгая TypeScript-структура данных, которой нужно точно соответствовать на выходе:

// Исходные интерфейсы
export interface INotation { 
  title: string;        // Название на русском языке
  description: string;   // Подробное описание на русском языке
}

export interface IStep extends INotation { 
  type: 'document' | 'code' | 'test' | 'exam';  // Тип шага
  experience: number;     // Опыт за шаг (можно распределять логически)
}

export interface ILevel extends INotation { 
  steps: IStep[];        // Детальные шаги внутри уровня
  experience: number;     // Суммарный опыт уровня
}

export interface IModule extends INotation { 
  levels: ILevel[];       // Уровни внутри модуля
  experience: number;      // Суммарный опыт модуля
}

// Финальная структура
studyPlanJSON: IModule[];

КЛЮЧЕВЫЕ ТРЕБОВАНИЯ К ГЕНЕРАЦИИ:

1. АДАПТИВНОСТЬ ПОД КОНКРЕТНЫЙ ЯЗЫК

Ты получил задачу на конкретный язык программирования. В промпте будет указано, для какого языка нужно составить план. Твоя задача - разработать план, учитывая ВСЕ особенности, синтаксис, парадигмы и возможности ИМЕННО ЭТОГО языка.

2. ЭКСТРЕМАЛЬНАЯ ДЕКОМПОЗИЦИЯ И ГЛУБИНА

Создай учебный план, который максимально детально раскладывает язык программирования на составляющие. Требуется ОЧЕНЬ ГЛУБОКАЯ декомпозиция:

- Модули (IModule): Создай 10-15 крупных модулей, покрывающих язык от абсолютных основ до самых продвинутых тем. Каждый модуль должен представлять крупный раздел языка.
  
- Уровни (ILevel) внутри модуля: Каждый модуль должен содержать 12-20 уровней. Уровни — это детальная разбивка темы модуля на микро-темы. Если тема сложная — создавай еще больше уровней. Цель: разложить каждую концепцию до мельчайших кирпичиков.

- Шаги (IStep) внутри уровня: Каждый уровень должен содержать 7-10 шагов. Шаги — это конкретные действия пользователя.

ИТОГОВЫЙ ОБЪЕМ: План должен содержать минимум 120-200 уровней и 800-1500 шагов. Это должен быть ОЧЕНЬ подробный учебный план, практически исчерпывающий.

3. ЛОГИКА ПОСТРОЕНИЯ КАЖДОГО УРОВНЯ

В каждом уровне соблюдай следующую структуру:

- Документация (2-3 шага): Теоретические шаги, где пользователь изучает концепцию.
  
- Практика (3-5 шагов): Шаги с написанием кода. Задания должны быть конкретными, выполнимыми, постепенно усложняться. От простых упражнений до мини-проектов.
  
- Тест (1 шаг): Проверка теоретического понимания. Распологается в центре уровня для закрепления 50% пройденного материала от уровня.
  
- Экзамен (1 шаг): Комплексное практическое задание, которое объединяет все знания уровня. Должно проверять реальное понимание.

4. СОДЕРЖАНИЕ И ОФОРМЛЕНИЕ

- Язык контента: Все title и description строго на русском языке.
  
- ОФОРМЛЕНИЕ ЗАГОЛОВКОВ (ВАЖНО!):
  - В полях title НЕ ДОБАВЛЯЙ никакую нумерацию (ни цифры, ни римские цифры, ни буквы)
  - НЕ ПИШИ в заголовках тип шага ("Документация:", "Практика:", "Тест:", "Экзамен:")
  - Заголовок должен быть просто короткой, информативной фразой, отражающей суть шага
  - Используй терминологию, специфичную для данного языка
  
- Качество описаний: Каждое описание должно быть подробным, инструктирующим. Для документации: "Изучи...", "Разбери...", "Пойми...". Для практики: "Напиши код, который...", "Создай функцию...", "Реализуй...".
  
- Опыт (experience): 
  - Документация: 5-10 единиц
  - Практика: 10-20 единиц
  - Тесты и экзамены: 0 единиц (проверочные шаги)

5. ФОРМАТ ВЫВОДА

Выведи ТОЛЬКО валидный JSON согласно структуре studyPlanJSON: IModule[]. Никаких пояснений, комментариев или дополнительного текста — только JSON.

ВАЖНО: Ты должен создать план для языка, который указан в задаче. Учитывай все его уникальные особенности, синтаксис, парадигмы, идиомы. План должен быть настолько подробным, чтобы по нему можно было выучить язык с нуля до продвинутого уровня, практически не прибегая к другим источникам. Никакой нумерации и указаний типа в заголовках!
