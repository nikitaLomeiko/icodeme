Задача: Разработать детальные шаги прохождения для конкретного уровня учебного плана по языку программирования #language#.

Контекст:
Мы создаем план для языка #language#.
Общее описание модуля: "#module_description#".
Мы работаем над уровнем внутри модуля "#module_title#".
Название текущего уровня: "#level_title#".
Подробное описание того, что нужно изучить на этом уровне: "#level_description#".

Твоя задача — создать третий, самый глубокий уровень декомпозиции: конкретные шаги (действия), которые пользователь должен выполнить для прохождения этого уровня.

КЛЮЧЕВЫЕ ТРЕБОВАНИЯ К ГЕНЕРАЦИИ:
1.  **ЛОГИКА ПОСТРОЕНИЯ УРОВНЯ:**
    *   **Документация (2-3 шага):** Первые шаги, где пользователь изучает теорию.
    *   **Тест (1 шаг):** Расположи этот шаг примерно в центре уровня (после первых 2-3 шагов документации и 1-2 шагов практики), чтобы закрепить 50% пройденного материала.
    *   **Практика (3-5 шагов):** Шаги с написанием кода, постепенно усложняющиеся.
    *   **Экзамен (1 шаг):** Последний шаг уровня. Комплексное задание, проверяющее понимание всего уровня целиком.

2.  **КОЛИЧЕСТВО ШАГОВ:** В сумме уровень должен содержать 7-10 шагов, распределенных согласно логике выше.

3.  **СОДЕРЖАНИЕ И ОФОРМЛЕНИЕ:**
    *   **Тип шага (`type`):** Строго один из: `'document'`, `'code'`, `'test'`, `'exam'`. (Экзамен — это тоже `'exam'`, а не `'code'`).
    *   **Заголовок (`title`):**
        *   На русском языке.
        *   **НЕ ПИШИ** в заголовке тип шага ("Документация:", "Практика:", "Тест:", "Экзамен:").
        *   **НЕ ИСПОЛЬЗУЙ** нумерацию.
        *   Заголовок должен быть короткой, информативной фразой, отражающей суть конкретного действия (например, "Что такое замыкание?", "Пишем функцию-счетчик", "Проверка знаний о лексическом окружении").
    *   **Описание (`description`):**
        *   Подробное, инструктирующее описание на русском языке.
        *   Для `'document'`: "Изучи статью о...", "Разбери принцип работы...", "Прочитай документацию по...".
        *   Для `'code'`: "Напиши функцию, которая...", "Создай класс...", "Исправь ошибку в коде...", "Реализуй алгоритм...".
        *   Для `'test'`: "Ответь на вопросы о..." (подразумевается, что контент теста будет добавлен позже, но описание должно его анонсировать).
        *   Для `'exam'`: "Напиши программу, которая объединяет все знания уровня: ..." (дай четкое ТЗ).
    *   **Опыт (`experience`):**
        *   `'document'`: 5-10 единиц.
        *   `'code'`: 10-20 единиц (чем сложнее задание, тем больше опыта).
        *   `'test'` и `'exam'`: 0 единиц (это проверочные шаги).

ФОРМАТ ВЫВОДА:
Выведи ТОЛЬКО валидный JSON-объект, который соответствует структуре:

[
  {
    "title": "Название первого шага",
    "description": "Подробное описание первого шага",
    "type": "document",
    "experience": 5
  },
  {
    "title": "Название второго шага",
    "description": "Подробное описание второго шага",
    "type": "document",
    "experience": 5
  },
  {
    "title": "Название третьего шага",
    "description": "Подробное описание третьего шага",
    "type": "code",
    "experience": 15
  },
  // ... (тест, еще код, и в конце экзамен)
  {
    "title": "Название экзаменационного шага",
    "description": "Подробное описание итогового задания",
    "type": "exam",
    "experience": 0
  }
]

Никаких пояснений, вступлений или заключений — только JSON.
